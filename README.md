# 🧩 Word Unscramble Game App

A **single-player word puzzle game** built using **Jetpack Compose**, **ViewModel**, and **StateFlow**. The player is presented with a scrambled word and must **unscramble it using all the letters** to form a valid word.

This app was developed by following the official Google Code Lab:

🔗 [Basic Android with Compose: ViewModel and State](https://developer.android.com/codelabs/basic-android-kotlin-compose-viewmodel-and-state#0)

---

## 🚀 Features

- ✅ Single-player gameplay
- 🔤 Random scrambled word shown
- ✍️ Player inputs the correct word using all letters
- 💡 Feedback on correct/incorrect guesses
- ♻️ Option to skip words
- 🎯 Score tracking
- 📱 Built entirely with **Jetpack Compose**
- ⚙️ Uses **ViewModel** and **StateFlow** for state management
